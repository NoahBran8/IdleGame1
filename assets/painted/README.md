# Painted miniature art — 0.7

These ten original game assets were generated for Garden Empire using OpenAI image_gen during this development session. The cottage was generated from an original written brief. The other assets used only that project-generated cottage as an aesthetic reference. No competitor artwork, franchise imagery, downloaded stock pack, concept-image crop, logo or external photograph was supplied. They are painted-style generated artwork, not a claim of human hand painting or involvement by any named game designer.

Every PNG has a transparent background and depicts a separate object: cottage, market, well, tree, pond, carrot, sunflower, rose, lavender or orchid. Functional buildings remain independent Buttons. Crops retain individual bed controls and alpha-aware hits. The assets are not a flattened game interface or full-scene backdrop. provenance.json records generation IDs, source checksums and runtime size limits. The original PNG outputs are retained here without cropping or external editing.

Godot import settings cap world textures at 256px and crops at 128px with mipmaps. The source PNGs total about 16 MiB; imported runtime pixel storage is roughly 2.1 MiB including mip levels before engine overhead. This is an estimate, not device memory profiling. Shared texture references are reused across beds, counter stock and selector cards. Original source resolution is preserved for future art work.

The project uses generated outputs rather than a separately licensed third-party asset library. No additional pack attribution or font license is introduced. Existing Godot/bundled-font notices continue to apply. Exclusivity, trademark clearance and release legal review are not asserted.
